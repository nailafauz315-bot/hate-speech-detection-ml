# Hate Speech Detection Using Machine Learning

## Project Overview

This project explores the classification of text into hate speech and non-hate speech categories using machine learning and Natural Language Processing (NLP).

It is a reconstructed learning implementation based on my original academic minor project topic.

## Objectives

* Understand text preprocessing and NLP fundamentals.
* Convert text into numerical features using TF-IDF.
* Train a machine learning classification model.
* Evaluate model predictions using standard classification metrics.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Natural Language Processing (NLP)
* TF-IDF Vectorization
* Logistic Regression

## Methodology

1. Load a labeled text dataset.
2. Clean and prepare the text data.
3. Convert text into numerical features using TF-IDF.
4. Split the data into training and testing sets.
5. Train a Logistic Regression classifier.
6. Evaluate predictions using precision, recall, F1-score, and a confusion matrix.

## Dataset

A suitable labeled dataset must be obtained separately. The dataset should contain text samples and their corresponding labels. Its source, license, and limitations should be documented before use.

## Current Status

## Limitations

* Text classification can produce false positives and false negatives.
* Meaning and context can be difficult for a model to interpret.
* Dataset bias can affect model predictions.
* This project is for learning purposes, not automated high-stakes decisions.
